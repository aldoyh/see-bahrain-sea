== Description ==

Bondigi Ocean is a deep ocean remix of the Bondigi WordPress block theme. Dive into abyssal blues, cyan reefs, and coral accents. Sleek layouts, vibrant gradients, and bold typography deliver a high-impact experience across every device. Fully optimized for Full Site Editing.
